# Agenda Surat Masuk – Dinas Kehutanan Provinsi Jawa Barat

Aplikasi web Agenda Surat Masuk yang menggunakan **Google Sheets** sebagai database.

## Fitur

- Statistik Total / Ditampilkan / Hari ini
- Pencarian nomor surat, asal, isi ringkas
- Filter Jenis Surat, Disposisi, Bulan
- Sorting kolom
- Pagination
- Detail surat (modal)
- Export CSV
- Responsif (mobile-friendly)

## Cara Deploy ke GitHub Pages

1. Buat repository baru di GitHub (misalnya `agenda-surat-masuk`)
2. Upload semua file di folder ini
3. Buka **Settings → Pages**
4. Source: **Deploy from a branch** → Branch `main` → Folder `/ (root)`
5. Simpan, tunggu beberapa menit
6. Link akan muncul: `https://USERNAME.github.io/agenda-surat-masuk/`

## Cara Pakai Lokal

Cukup buka file `index.html` di browser.
